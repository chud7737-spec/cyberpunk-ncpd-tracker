# NCPD Tracker (Трекер активности полиции) - ПРОТОТИП

**Внимание: Это Диагностический Прототип / Development build.**

Мод для Cyberpunk 2077 (версия 2.31 + Phantom Liberty), предназначенный для диагностики и тестирования API, необходимых для показа всех незавершённых активностей NCPD.

## Установка
1. Запусти `tools/build_dist.py` или скачай готовый release.
2. Возьми папку `dist/NCPD_Tracker`.
3. Скопируй её в:
`Cyberpunk 2077\bin\x64\plugins\cyber_engine_tweaks\mods\`
4. Проверь наличие файла:
`Cyberpunk 2077\bin\x64\plugins\cyber_engine_tweaks\mods\NCPD_Tracker\init.lua`
5. Запусти игру.
6. Открой CET.
7. Открой NCPD Tracker.
8. Нажми "Тестовая метка возле игрока".
9. Открой карту.
10. Убедись, что marker появился.
11. Нажми "Удалить тестовую метку".
12. Убедись, что marker исчез.

## Ограничения прототипа

*   **Только Диагностика:** Эта сборка включает DEBUG секцию в UI CET для создания тестовых маркеров возле игрока и проверки `JournalManager`.
*   **Определение завершения:** В данный момент мод возвращает статус `UNKNOWN` для квестов, так как для точной проверки через `JournalManager` требуются точные пути (journal paths), которые нужно извлечь из ресурсов игры. Для безопасности маркеры для статуса `UNKNOWN` не отображаются.
*   **Координаты:** В базе данных сейчас нет проверенных координат. Их нужно извлечь парсером `tools/extract_ncpd.py` (который пока не реализован) из дампов WolvenKit.
