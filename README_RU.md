# NCPD Tracker (Трекер активности полиции) - ПРОТОТИП

**Внимание: Это Прототип / Development build.**

Мод для Cyberpunk 2077 (версия 2.31 + Phantom Liberty), который позволяет видеть на карте **все незавершённые активности NCPD** (разбой, организованная преступность и заявленные преступления), включая те, которые ванильная игра скрывает из-за неисследованности района.

## Ограничения прототипа

*   **Определение завершения:** В данный момент мод возвращает статус `UNKNOWN` для квестов, так как для точной проверки через `JournalManager` требуются точные пути (journal paths), которые нужно извлечь из ресурсов игры. Для безопасности маркеры для статуса `UNKNOWN` не отображаются.
*   **Координаты:** В базе данных сейчас нет проверенных координат. Их нужно извлечь парсером `tools/extract_ncpd.py` из дампов WolvenKit.
*   **API Маркеров:** Использование `RegisterMappin` пока приблизительное и требует тестирования в самой игре для подтверждения правильного синтаксиса, чтобы избежать вылетов.

## Особенности
*   **Безопасность (READ ONLY):** Мод никак не изменяет прогресс, не завершает квесты, не открывает их искусственно и не меняет ваше сохранение. Он только читает текущее состояние и рисует маркеры на карте.
*   **Умное отслеживание:** Как только вы завершаете активность, маркер автоматически исчезает.
*   **Удобный интерфейс (CET):** Меню, где можно отфильтровать активности по районам или типам, а также посмотреть общую статистику завершения по районам.

## Требования
*   Cyberpunk 2077 v2.31
*   [Cyber Engine Tweaks (CET)](https://www.nexusmods.com/cyberpunk2077/mods/107) последней версии

## Установка
1.  Установите Cyber Engine Tweaks, если он еще не установлен.
2.  Скачайте архив мода `NCPD_Tracker.zip`.
3.  Распакуйте содержимое архива в папку игры (туда, где находится папка `bin`).
    *   Путь должен получиться таким: `Cyberpunk 2077\bin\x64\plugins\cyber_engine_tweaks\mods\NCPD_Tracker\init.lua`
4.  Запустите игру.

## Как использовать
1.  Откройте оверлей Cyber Engine Tweaks (клавиша, которую вы назначили при первом запуске CET).
2.  Найдите окно "NCPD Tracker".
3.  Здесь вы можете посмотреть свою статистику, включить нужные фильтры (например, показать активности только в Уотсоне) и обновить маркеры.
4.  Откройте игровую карту. Все активные метки будут отображены как **Вопросительные знаки** (или иконки NCPD, если игра позволяет кастомные иконки в текущем состоянии).

## Удаление
Просто удалите папку `NCPD_Tracker` из `bin\x64\plugins\cyber_engine_tweaks\mods\`. Мод не оставляет следов в сохранении, так как работает только в оперативной памяти.
