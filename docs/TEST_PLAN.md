# Сценарии ручного тестирования

Эти тесты необходимо провести в самой игре для подтверждения работоспособности.

1. **Первый запуск**
   - Убедиться, что мод загрузился без ошибок.
   - Окно CET "NCPD Tracker" появляется.
   - База данных успешно загружена.

2. **Загрузка существующего save**
   - Загрузить сохранение.
   - Открыть карту, убедиться, что маркеры для незавершенных квестов (из базы) появились.

3. **Завершённая NCPD**
   - Убедиться, что для тех квестов из базы, которые игрок уже прошел, маркеры НЕ появляются.

4. **Выполнение NCPD при работающем моде**
   - Прийти на место незавершенной NCPD (маркер виден).
   - Завершить активность (забрать лут).
   - Убедиться, что через несколько секунд (или при переоткрытии карты) кастомный маркер пропал.

5. **Fast travel и смерть/reload**
   - Переместиться по фаст-тревелу. Убедиться, что маркеры не исчезли/не задвоились.
   - Умереть, загрузить сейв. Убедиться, что маркеры корректны (не сломались, не задвоились).

6. **Возврат в главное меню**
   - Выйти в главное меню.
   - Убедиться, что при выходе все кастомные маркеры снимаются с регистрации (`UnregisterMappin`), чтобы не перетечь в другое сохранение (если движок сам их не чистит).

7. **Район не исследован**
   - Загрузить новое сохранение (пролог пройден, но карта не открыта).
   - Убедиться, что метки мода отображаются, даже если ванильных меток там еще нет.
